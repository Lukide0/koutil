Detailed Description

template<typename From, typename To>
struct koutil::container::index_rule< From, To >

Defines a single allowed index conversion rule.

The rule can describe conversions between types, compile-time values, or a combination of both.

Template Parameters
FromThe source of the conversion rule.
ToThe destination of the conversion rule.

index_value<IndexTag::A>,

>;

index_value<IndexTag::C>,
