Detailed Description

template<typename ValueType, typename Tag>
class koutil::container::index_t< ValueType, Tag >

Strongly typed index value.

Conversions between different tags are disabled by default and must be explicitly enabled through allow_index_conversion.

Template Parameters
ValueTypeType used to store the index value.
TagTag identifying the index type.
Example
using player_index = index_t<std::uint32_t, PlayerTag>;
using enemy_index = index_t<std::uint32_t, EnemyTag>;
player_index user{5};
enemy_index func{user}; // Only valid if the conversion is allowed.
